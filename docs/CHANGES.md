# 변경 기록

0.1.0 개인용 통합판 · 이름: 담소 도구함 (Damso Tools)

- 원본 `baibai-git/ST-BaiBai-Tools@2f3a221e00dd713baba45e1f857d093141593c09`, package/manifest 1.0.0 기준. 원본 README의 0.30.13 표기와 구분.
- 화면 문자열을 AST와 HTML 문구 단위로 한국어 사전에 연결. 사용자 본문·매크로·정규식·식별자·음원 파일명·작성자는 유지.
- 외부 `/api/plugins/baibaoku/v1`, BaiBaoKu.database, client.js 주입과 driver/외부 버전 검사 제거. 자체 `/api/plugins/st-ko-tools/v1` 계약으로 변경.
- 기존 화면 설정 키와 프리셋 메타데이터는 그대로 사용. 원본과 동시 사용하지 않음.
- 백업은 원래 저장 성공 후 생성. 보관함은 expectedRevision 충돌 검사. 파일 저장은 원자적 교체.
- Tab 제한은 기본 끔. 재로딩 복구 보조는 같은 채팅의 읽기 실패가 관측된 경우만 화면을 복원하도록 변경하고 force-save를 제거. 정상 삭제·다른 창의 성공한 변경은 복원하지 않음. 기본 끔, 기존 사용자 설정은 유지.
- 생성은 검증할 수 있는 OpenAI/Custom 소스로 한정. 실제 호스트 생성 핸들러를 내보내 재사용하고 인증 키와 모델 규칙을 중복 구현하지 않음.
- 채팅 라우터에 공유 쓰기 조정과 revision 헤더 연결. 서버 작업도 같은 잠금과 전체 파일 SHA-256 revision을 사용.
- 설정·채팅 목록 캐시는 파일 mtime/ctime/크기로 무효화하고 원래 호스트 응답을 유지. 캐시를 삭제해도 사용자 데이터는 유지.
- Vite 호스트 import 경로는 배포 URL 기준으로 고정. 원본 자동 업데이트를 막고 통합 설치 도구로만 갱신.
- 호스트 패치 대상: index.html, chats.js, chat-completions.js, power-user.js, keyboard.js. 버전별 SHA-256과 문맥을 모두 검사.
- 같은 프로세스의 채팅 쓰기 잠금은 브라우저 연결 종료 후에도 실제 쓰기가 끝날 때까지 유지하고 응답 시도 후 해제. 생성 저장 표식은 메모리에도 반영해 뒤따르는 네이티브 저장에서 사라지지 않도록 함.
- 설치 중단 journal 복구와 Docker PUID/PGID 파일 권한 처리를 추가. ZIP 안의 source 폴더만으로 재빌드에 필요한 문서·자산·스크립트를 포함.
- 기존 Tab 탐색·백업 개수 등 알려진 설정만 최초 서버 설정으로 이관. 사용자별로 화면 확장이 없거나 비활성화되어 있으면 초기 가속을 적용하지 않음.

원본 소스와 음원·vendor 자산의 저작자 고지를 유지했습니다. `docs/upstream-README.md`는 원본 문서이며 현재 통합판의 설치 안내가 아닙니다.
